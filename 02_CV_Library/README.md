# Privacy-Safe CV Library

This public library contains ATS-oriented resume variants for UAE, India, and Saudi Arabia roles. Every public version omits phone numbers and raw email addresses and uses LinkedIn as the professional contact route.

## Recommended versions

- `01_UAE/02_HR_Coordinator` - primary UAE HR coordination version
- `01_UAE/01_General_HR` - broader UAE HR operations version
- `02_India/01_General_HR` - primary India HR operations version

## Developmental or limited-use versions

- `01_UAE/03_HR_Analyst` - junior reporting and people-analytics support
- `01_UAE/04_Compensation_and_Benefits` - supervised entry-level C&B support
- `03_Saudi_Arabia/01_General_HR` - roles explicitly open to international applicants

## Publication rules

- HTML is the canonical editable format and is eligible for Git tracking.
- Sanitized matching PDFs are public application artifacts and are explicitly allowed by the root Git policy.
- Do not add a phone number, government identifier, street address, or raw personal email to a public resume.
- Re-run the pre-push privacy suite after every content update.
